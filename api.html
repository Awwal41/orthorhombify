API reference¶

Everything below is importable from the top-level package:

import orthorhombify as orth

Supercells¶

orthorhombify.find_supercells(atoms, max_cells=6, top=2, *, mode='auto', method='vectors', angle_tol=0.001, tol=None, anis_max=None, max_index=None, unimod=2, fast=False, gate=None, stop_on_tol=False)[source]¶

Find integer supercells whose angles are as close to 90 degrees as possible.

Parameters:

  • atoms – ASE Atoms, a 3x3 cell matrix, or [a, b, c, alpha, beta, gamma].

  • max_cells (int) – Largest supercell to try, in unit cells.

  • top (int) – How many candidates to return (best first).

  • mode (str) – "auto" (pick the search from the cell shape), "monoclinic" (2D search around the unique axis) or "triclinic" (3D search).

  • method (str) – 3D search only. "vectors" (default; fast, searches all short lattice vectors) or "hnf" (the original v1 search).

  • angle_tol (float) – Detection tolerance: an angle within this many degrees counts as 90.

  • tol (float | None) – Return the smallest supercells within tol degrees first. With method="hnf" and stop_on_tol: stop once the summed deviation <= 3*tol.

  • anis_max (float | None) – Skip boxes whose longest/shortest edge ratio exceeds this.

  • max_index (int | None) – Largest integer coefficient tried for the new axes. Default 12 for the 2D search and 5 for the 3D search.

  • unimod (int) – method="hnf" controls (see the CLI docs).

  • fast (bool) – method="hnf" controls (see the CLI docs).

  • gate (float | None) – method="hnf" controls (see the CLI docs).

  • stop_on_tol (bool) – method="hnf" controls (see the CLI docs).

Returns:

A list of Candidate, best first. Cells that are already orthogonal (cubic, tetragonal, orthorhombic) return the identity.

Return type:

list[Candidate]

orthorhombify.detect_system(cell, angle_tol=0.001, length_tol=0.0001)[source]¶

Classify a cell by its shape (lengths and angles, not by symmetry).

Parameters:

  • cell – ASE Atoms, a 3x3 cell matrix, or [a, b, c, alpha, beta, gamma].

  • angle_tol (float) – Two angles are equal if within this many degrees.

  • length_tol (float) – Two lengths are equal if within this relative difference.

Returns:

(system, unique_axis). system is one of "cubic", "tetragonal", "orthorhombic", "hexagonal" (two equal edges at 120 or 60 degrees), "monoclinic", "rhombohedral" (equal edges, three equal angles) or "triclinic". unique_axis is 0, 1 or 2 (a, b, c) for hexagonal and monoclinic cells (the axis at 90 degrees to the other two), otherwise None.

orthorhombify.build_supercell(atoms, P, force_orthogonal=False)[source]¶

Build the supercell P @ cell of atoms.

The result is rigidly rotated to the standard orientation (a along x, b in the xy plane) and atoms are wrapped into the box. No strain is applied unless force_orthogonal is set, which makes the box exactly 90/90/90 while keeping fractional coordinates; the largest Green-Lagrange strain component is stored in result.info["orthorhombify_strain"].

Parameters:

  • atoms (Atoms)

  • force_orthogonal (bool)

Return type:

Atoms

Lattice directions¶

class orthorhombify.LatticeMapping(P)[source]¶

Axes, directions and planes of an old cell expressed in a new cell, and back.

Parameters:

P – 3x3 transformation, new_cell_rows = P @ old_cell_rows. Integers, floats or fraction strings ("1/2") are all fine.

Example:

m = LatticeMapping([[1, 0, 1], [0, 1, 0], [-4, 0, 3]])
m.new_axis_expressions()      # ["a + c", "b", "-4a + 3c"]
m.direction_to_new([1, 1, 0]) # old [110] in new-cell coordinates
m.plane_to_old([0, 0, 1])     # Miller indices of the new (001) plane in the old cell

Other cells and going back¶

orthorhombify.transform(atoms, matrix, *, reduce='auto', tol=0.5)[source]¶

Build the cell matrix @ cell of atoms and fill it with the right atoms.

Parameters:

  • atoms (Atoms) – The structure.

  • matrix – 3x3 transformation (ints, floats, fraction strings), or text in the command-line form such as "1 0 0; -1/2 1/2 0; 0 0 1" or "2 2 1". new_cell_rows = matrix @ old_cell_rows.

  • reduce (str) – Only used when the new cell is smaller (fractional matrix). "average" averages every copy of each atom, which is the right choice for a supercell built by Orthorhombify (copies are stored one after another), including after an MD run. "dedup" folds all atoms into the new cell and merges atoms of the same element closer than tol. "auto" uses average if the atom order allows it, otherwise dedup.

  • tol (float) – Distance (Å) under which folded atoms count as the same atom (dedup), and the largest allowed spread between copies of one atom (average).

Returns:

New Atoms in the standard orientation (a along x, b in the xy plane). info["orthorhombify_reduce"] records which method was used and info["orthorhombify_P"] the matrix (as fraction strings).

Return type:

Atoms

orthorhombify.back_to_original(atoms, mapping_json, *, replicate=None, reduce='auto', tol=0.5)[source]¶

Undo an Orthorhombify step: go from the (equilibrated) supercell back to the original cell, using the *_orth_N.json file written next to it.

Parameters:

  • atoms (Atoms) – The supercell, for example read from the LAMMPS *_equil.data file.

  • mapping_json (str) – The .json file written by orthorhombify.

  • replicate – (nx, ny, nz) if the box was replicated in LAMMPS. Worked out from the atom count and box lengths if not given.

  • reduce (str) – See transform().

  • tol (float) – See transform().

Returns:

The structure in the original cell. info["orthorhombify_replicate"] records the replication that was undone.

Return type:

Atoms

orthorhombify.write_lammps_inputs(atoms, outdir, name, *, charges=None, neutralize=True, ffield='ffield.reax', lgvdw=False, temp=300.0, press=1.0, timestep=0.1, nvt_steps=10000, npt_steps=50000, barostat='aniso', minimize=True, replicate=None, seed=4928459)[source]¶

Write <outdir>/<name>.data and <outdir>/in.<name>.

Parameters:

  • atoms (Atoms) – The structure (any cell; LAMMPS tilt factors are written if needed).

  • outdir (str) – Folder to write into (created if missing).

  • name (str) – Base name of the files.

  • charges (dict | None) – {element: charge} overrides; defaults are DEFAULT_CHARGES.

  • neutralize (bool) – Shift every charge by the same amount so the total is zero.

  • ffield (str) – ReaxFF force-field file name used in pair_coeff.

  • lgvdw (bool) – Force field is ReaxFF-lg (adds lgvdw yes).

  • temp (float) – Temperature (K).

  • press (float) – Pressure (atm).

  • timestep (float) – Timestep (fs).

  • nvt_steps (int) – Number of NVT steps.

  • npt_steps (int) – Number of NPT steps.

  • barostat (str) – "aniso" (keeps angles), "iso", or "tri" (relaxes angles).

  • minimize (bool) – Run an energy minimization first.

  • replicate – (nx, ny, nz) to add a replicate command after read_data.

  • seed (int) – Random seed for the starting velocities.

Return type:

LammpsFiles
