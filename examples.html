Examples¶

Four energetic molecular crystals, all monoclinic, all space group 14.

Try it now: beta-HMX comes from the open Crystallography Open Database (COD 4110146) and ships inside the package:

from ase.io import read
import orthorhombify as orth

atoms = read(orth.example_path("beta_HMX"))
best = orth.find_supercells(atoms, max_cells=8, top=1)[0]
print(best.n_cells, best.angles)       # 7 (90.0, 89.999, 90.0)

or from the terminal (in a clone it is src/orthorhombify/data/beta_HMX.cif):

orthorhombify path/to/beta_HMX.cif --max-cells 8 --top 1 --outdir output
orthorhombify-lammps output/beta_HMX_orth_1.cif --outdir lammps

The other three come from the Cambridge Structural Database (CSD) and are not in this repository. Download them from the CCDC with the refcodes below, then run the same commands on them.

At N = 7 the box is orthorhombic to 0.001 degrees. For comparison, the original v1 script (--max-cells 12) gave 90.83 degrees with 448 atoms.

TNT (monoclinic)¶

N=1: 20.182  N=2: 0.470  N=4: 0.130
[1] N=4 (672 atoms)  a,b,c = 21.4070, 56.0840, 6.0932 A   gamma = 90.130

For a smaller box, --tol 0.5 picks N = 2: 15.02 x 39.97 x 6.09 Å, 336 atoms, gamma = 89.53.

The starting charges are far from neutral for TNT (-97.42 e for 672 atoms), so the neutralizing shift is large (+0.145 e per atom). Consider giving TNT its own charges. See LAMMPS files and charges.

FOX-7¶

N=1 ... N=8: 0.065
[1] N=1 (56 atoms)  beta = 90.065

The unit cell is already the closest to 90 degrees. No supercell does better. If you need exactly 90, --force-orthogonal squares it with a strain of only 5.7e-4. The box is small (6.9 x 6.6 x 11.3 Å), so use --replicate 3 4 2 for LAMMPS.
